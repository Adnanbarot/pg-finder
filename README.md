# PG Finder

PG Finder is a web platform designed to help students and working professionals find suitable PGs and hostels based on their location, budget, room type, and required facilities.

## Problem

Finding suitable accommodation can be difficult because information about PGs is often scattered across different sources. Users may have to contact multiple owners or brokers before finding a suitable option.

## Solution

PG Finder aims to bring accommodation listings into one platform where users can search, filter, compare, and enquire about suitable PGs.

## Planned Features

- Search PGs by location
- Filter by budget and room type
- View PG details and facilities
- Save preferred PGs
- Send enquiries
- User accounts
- PG owner listings
- Owner dashboard
- Admin dashboard

## Technology

- Frontend: React
- Backend: Python / FastAPI
- Database: PostgreSQL
- Version Control: Git & GitHub
